## **🦀 unsafe-calc**

> Could I have used `Vec`? Absolutely. Did I? No.

*Why not rewrite a Python calculator in Rust?*

*Why not take ownership?*

A small scientific calculator rewritten in Rust and compiled to WebAssembly.

It started as a simple experiment to learn Rust.

It somehow ended up with a custom `unsafe` stack, raw pointers, and manual memory management.

**Origin**

This project started as a rewrite of my old Python calculator.

It became my excuse to dive into Rust—and here's the result. ;D
